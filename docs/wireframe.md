## 2. 화면 구획별 상세 UI/UX 명세

### 2.1 상단 컨트롤 & 헤더 프로필
- **테마 전환기**: 라이트 모드(화이트/소프트 그레이) ↔ 다크 모드(딥 차콜/다크 그레이) 토글
- **원형 아바타 (Avatar)**: `w-24 h-24`, 둥근 모서리와 은은한 그림자, 활동 배지 표시
- **표시 이름 & 직무 배지**: Pretendard 볼드 타이포그래피 + 연한 블루 톤의 직무/역할 배지
- **소개글 (Bio)**: 가독성 높은 그레이 컬러(`text-[#4E5968]`), 2~3줄 이내 요약
- **이메일 원클릭 복사 알약**:
  - 터치 시 클립보드에 이메일 저장
  - 하단에 토스 스타일 플로팅 토스트(`이메일 주소를 복사했어요`) 2초간 노출

### 2.2 소셜 아이콘 바 (Social Links Bar)
- 원형 플로팅 버튼(`w-10 h-10`), 가벼운 외곽선과 그림자
- 마우스 호버 시 살짝 확대(`scale-105`), 클릭 시 누름 효과(`active:scale-95`)
- GitHub, LinkedIn, Instagram, X(Twitter) 등 등록된 URL만 렌더링

### 2.3 카테고리별 링크 카드 (Link Cards)
- **섹션 타이틀**: 카테고리명(예: `프로젝트`, `블로그`)과 등록된 링크 개수 카운트
- **카드 본체**:
  - `rounded-2xl` (16px), 부드러운 화이트 카드 (다크모드는 `#1E1E1E`)
  - 타이틀, 강조 뱃지(`HOT`, `NEW`, `추천`), 상세 설명, 기술 태그
  - 우측 화살표 아이콘(Chevron)으로 명확한 클릭 어포던스 제공
- **인터랙션**: 카드 클릭 시 `active:scale-[0.98]` 햅틱 스타일 마이크로 애니메이션

### 2.4 푸터 (Footer)
- 서비스명("마이링크 • myLink") 및 라이선스/기술 스택 표기
- 브라우저 하단 안전 영역(Safe Area) 여백 확보
